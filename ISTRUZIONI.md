# Tracker Spese su GitHub Pages (solo dal browser)

## Prima volta
1. Crea un account su github.com e un repository **pubblico** chiamato `tracker-spese` (senza README).
2. Nel repository: **Settings → Pages → Source: GitHub Actions**.
3. Estrai lo zip in una cartella NUOVA. Torna sul repository → **uploading an existing file**, trascina TUTTO il contenuto della cartella `tracker-spese` e premi **Commit changes**.
4. Scheda **Actions**: aspetta la spunta verde (1-3 minuti). L'app è su `https://TUO-UTENTE.github.io/tracker-spese/`.
5. Apri l'indirizzo su PC e telefono, installa l'app e in Impostazioni → Sincronizzazione collega Supabase.

## Ogni aggiornamento
Estrai il nuovo zip in una cartella nuova → repository → **Add file → Upload files** → trascina tutto → **Commit changes**. Dopo 1-3 minuti apri l'app e tocca **Aggiorna** nel banner.

## Regole d'oro
Non cambiare mai l'indirizzo, non eliminare l'icona dalla Home, apri l'app almeno una volta a settimana.
